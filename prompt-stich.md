# Prompt para Stitch - Prototipo Hogar360

Diseña el prototipo visual de una aplicación móvil llamada **Hogar360**.

## Objetivo de la app

Hogar360 ayuda a personas que están remodelando su hogar a calcular materiales de forma sencilla. La primera versión tiene dos funciones principales:

1. Calcular cuántas mayólicas o cajas se deben comprar para cubrir un piso.
2. Mostrar una paleta de colores de pintura para que el usuario pueda elegir un color antes de ir a la ferretería.

La app también debe incluir login y registro.

## Estilo visual

Crear una interfaz móvil moderna, limpia y amigable para usuarios no técnicos.

Usar una estética de hogar/remodelación:

- Colores cálidos y claros.
- Verde suave como color principal.
- Blanco o gris muy claro para fondos.
- Acentos en terracota, amarillo cálido o azul suave.
- Botones visibles y fáciles de tocar.
- Iconos relacionados con casa, piso, pintura y calculadora.

Evitar que parezca una app bancaria o empresarial. Debe sentirse práctica, cercana y útil para el hogar.

## Pantallas necesarias

### 1. Splash Screen

Pantalla inicial con:

- Logo o nombre Hogar360.
- Frase corta: "Calcula materiales para tu hogar".
- Fondo limpio y cálido.

### 2. Login

Pantalla de inicio de sesión con:

- Campo de correo.
- Campo de contraseña.
- Botón "Iniciar sesión".
- Enlace a "Crear cuenta".
- Diseño simple, centrado y claro.

### 3. Registro

Pantalla de registro con:

- Nombre completo.
- Correo.
- Contraseña.
- Confirmar contraseña.
- Botón "Registrarme".
- Enlace para volver al login.

### 4. Menú principal

Pantalla después del login.

Debe mostrar dos opciones grandes:

- "Calcular mayólicas"
- "Elegir color de pintura"

Cada opción debe tener un icono o ilustración sencilla. El diseño debe ser claro para que el usuario entienda rápidamente qué hacer.

### 5. Calculadora de mayólicas

Pantalla con formulario para ingresar:

- Largo del piso.
- Ancho del piso.
- Largo de la mayólica.
- Ancho de la mayólica.
- Mayólicas por caja.
- Porcentaje de merma.

Agregar un botón principal: "Calcular".

El formulario debe verse ordenado, con campos grandes y etiquetas claras. Usar unidades visibles como metros o centímetros.

### 6. Resultado de cálculo

Pantalla o sección de resultado con:

- Área total del piso.
- Cantidad de mayólicas necesarias.
- Porcentaje de merma aplicado.
- Total recomendado de mayólicas.
- Número de cajas a comprar.

El resultado principal debe destacar: "Compra X cajas".

Agregar botones:

- "Nuevo cálculo".
- "Guardar resultado".

### 7. Paleta de colores de pintura

Pantalla con una grilla de colores.

Cada color debe mostrar:

- Muestra visual del color.
- Nombre del color.
- Código hexadecimal.
- Familia de color.

Agregar filtros simples por familia:

- Todos.
- Verdes.
- Azules.
- Neutros.
- Cálidos.

### 8. Detalle de color

Pantalla o modal al seleccionar un color.

Debe mostrar:

- Color en grande.
- Nombre.
- Código hexadecimal.
- Recomendación breve, por ejemplo: "Ideal para salas luminosas".
- Botón "Guardar color".

## Navegación esperada

Flujo:

Splash -> Login -> Registro opcional -> Menú principal -> Calculadora de mayólicas -> Resultado.

Flujo alternativo:

Menú principal -> Paleta de colores -> Detalle de color.

## Requisitos de diseño móvil

- Priorizar diseño para Android.
- Pantallas verticales.
- Componentes grandes y táctiles.
- Texto legible.
- Formularios claros.
- Nada de pantallas saturadas.
- Usar tarjetas solo para opciones, resultados o colores.

## Personalidad de marca

Hogar360 debe sentirse:

- Práctica.
- Confiable.
- Casera.
- Simple.
- Amigable.

No debe sentirse técnica ni complicada.
